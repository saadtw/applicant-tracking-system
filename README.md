# Applicant Tracking System

A generic Applicant Tracking System (ATS) designed to streamline the hiring process for organizations.

## Features

- **Job Creation:** Easily create and manage job postings.
- **Candidate Management:** Track applicants through various stages (Applied, Recommended, Hired, Declined, Withdrawn).
- **Interview Scheduling:** Set up and manage online interviews.
- **Bulk Emailing:** Send automated acceptance or rejection emails to multiple candidates simultaneously.
- **Data Visualization:** Interactive dashboards to manage and visualize applicant records.
- **End-User Portal:** A clean interface for candidates to view job details and submit applications.

## Tech Stack

- **Client:** React, Redux Toolkit, TailwindCSS, DaisyUI
- **Server:** Node.js, Express.js
- **Database:** MongoDB Atlas

## Installation & Setup

1. Install dependencies for both Client and Server:
```bash
npm install
```

2. Start the Backend Server:
```bash
npm run start
```

3. Start the Frontend Client:
```bash
npm run dev
```
